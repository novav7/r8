Practical No. 7
Web Automation: Element Enumeration & Categorized Component Count
Aim
Write a program to identify and count the total number of objects present on a web page including
links, images, buttons, and input elements. Display categorized counts.
Steps:-
1. Open Notepad and type this code and save file as Practical7.py
Code:-
from playwright.sync_api import sync_playwright
def test_object_counting():
with sync_playwright() as p:
browser = p.chromium.launch(channel="chrome", headless=False)
context = browser.new_context()
page = context.new_page()
try:
print("Navigating to target web page...")
page.goto("https://rahulshettyacademy.com/AutomationPractice/")
print("Identifying and counting web elements...")
links = page.locator("a")
link_count = links.count()
images = page.locator("img")
image_count = images.count()
buttons = page.locator("button, input[type='button'], input[type='submit']")
button_count = buttons.count()
inputs =
page.locator("input:not([type='hidden']):not([type='checkbox']):not([type='radio']):not
([type='button']):not([type='submit'])")
input_count = inputs.count()
total_elements = page.locator("*").count()
