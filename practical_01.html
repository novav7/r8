Practical No.1
Selenium IDE: Multi-Format Validation Test Suite & WebDriver Export
Aim
To install Selenium IDE and create a test suite containing a minimum of four test cases to
validate different web page formats such as HTML page, XML response, JSON API output,
and a dynamic form page. Execute the test suite and export the automation script in
WebDriver format.
Steps:-
1. Open Microsoft Edge and Search “Selenium IDE edge extension” then Click on the
first website. Click on “Get” to add extension in your browser.
2. After adding extension click on extension icon and pin the Selenium IDE extension.

Test Suite Execution
After creating all four test cases:
1. Open the Selenium IDE project.
2. Select the test suite.
3. Rename Test Suite To Practical1
4. Right click on the test suite and add all 4 test we created
5. Verify that all four test cases are present.

7. Observe the execution log.
