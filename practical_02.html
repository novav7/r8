Aim
Practical No. 2
Selenium IDE: Cross-Website Functional Test Suite Execution &
Verification
To develop and execute a cross-website functional test suite using Selenium IDE for two
different websites. The test suite performs functional operations such as opening web pages,
entering data into forms, clicking buttons, adding a product to the shopping cart, and
verifying the displayed content.
Steps:-
1. Click on the Selenium IDE extension to open Selenium IDE.
2. Click on Create a new project and enter the project name: Practical 2

Test Case 1 – Demo Sauce Test Case
Base URL
https://www.saucedemo.com
Objective
To verify the login functionality of the Sauce Demo website, add a product to the shopping
cart, navigate to the cart, and verify that the selected product is displayed.
Test Data
Username: standard_user
Password: secret_sauce
Product: Sauce Labs Backpack
