Practical No. 6
Web Automation: Dynamic Table Data Extraction & Conditional Analytics
Aim
Automate extraction of student marks from a dynamic web table and determine the number of
students scoring above 60 in at least one subject. Compute total count and percentage.
Steps:-
1. Open Notepad and type this code and save file as Practical6.py
Code:-
from playwright.sync_api import sync_playwright
def test_web_table_score_analysis():
with sync_playwright() as p:
browser = p.chromium.launch(channel="chrome", headless=False)
context = browser.new_context()
page = context.new_page()
try:
print("Navigating to table test page...")
page.goto("https://www.w3schools.com/html/html_tables.asp")
print("Extracting data from the web table...")
table_rows = page.locator("table#customers tr")
row_count = table_rows.count()
print(f"Total rows found in table: {row_count}")
total_students = 0
scoring_above_60_count = 0
for i in range(1, row_count):
row = table_rows.nth(i)
columns = row.locator("td")
if columns.count() > 0:
total_students += 1
has_scored_above_60 = False
